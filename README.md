> My AI agent wrote a function so elegant, so clean, so well-documented — it solved a problem we never had, in a file we were about to delete.

Run it with Node 22:

```
node main.ts
```

It writes the joke to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
